## Kinnect Web Prototype

This repository now includes a browser-based prototype for Kinnect, the friend-finding application described in the requirements and architecture documents.

### Run locally

Open `prototype/index.html` in a browser, or serve the repository folder with a simple static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/prototype/`.

### Implemented prototype features

- Nearby friend discovery with a map-style interface
- Radius, location-sharing, and interest-tag filtering
- Public profile drawer with shared interests and external chat handles
- Route request simulation between nearby users
- Messaging and group chat simulation
- Profile editing with anonymous mode and custom interest tags
- Location-triggered video post preview
