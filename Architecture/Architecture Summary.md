# Architecture Summary

The architecture we intend to use for this project will be the client-server pattern.

## Frontend
Our frontend should be component-based, consist 4 components:
 - Map UI
 - Profile UI
 - Chat UI
 - Video UI

## Backend
Our backend should consist 4 components:
 - User service
 - Location service
 - Tag service
 - Chat service

## Database
Our database should consist 4 components:
 - User database
 - Location cache
 - Message database
 - Media storage
